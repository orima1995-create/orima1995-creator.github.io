# PDFを画像認識して「海外語→日本語」に差し替えるアプリ設計（ヴィンテージ腕時計特化）

あなたの要望（**人間に近い画像認識 / 専門家目線の和訳 / レイアウト維持**）を実現するには、以下の4段パイプラインが最短です。

---

## 1. 目標仕様（MVP）
- PDFをアップロード
- ページを画像化してOCR
- テキストをブロック単位で抽出（位置座標つき）
- 腕時計専門辞書を使って翻訳（英語・仏語・伊語など）
- 元の座標に**日本語テキストを再配置**して新PDFを書き出し

---

## 2. 推奨アーキテクチャ

```text
Frontend (Next.js)
  └─ PDFアップロード / 進捗 / プレビュー

Backend API (Python FastAPI)
  ├─ PDF分解: PyMuPDF
  ├─ OCR: PaddleOCR or Tesseract + レイアウト解析(LayoutParser)
  ├─ 翻訳: OpenAI API (用語集 + スタイルガイド)
  ├─ 組版: ReportLab or PyMuPDFで再合成
  └─ QA: 数値・型番・単位の自動検証

Storage
  ├─ 元PDF
  ├─ 中間JSON（bbox, 原文, 言語, 翻訳文）
  └─ 出力PDF
```

---

## 3. 翻訳品質を上げる鍵（腕時計ドメイン）

### A. 用語集（必須）
- `calibre` → 「キャリバー」
- `chronometer` → 「クロノメーター（公認精度規格）」
- `sub-seconds` → 「スモールセコンド」
- `service history` → 「整備履歴」
- `caseback` → 「裏蓋」

### B. 翻訳ルール（必須）
- 型番、リファレンス、シリアル、寸法、年代表記は**原文維持**
- 価格や通貨記号は**変換せず保持**
- 曖昧語（excellent, very good）は販売文脈に合わせて自然な和訳

### C. 文章トーン
- EC掲載向け：簡潔・信頼重視
- オークション向け：由来と希少性を丁寧に

---

## 4. レイアウト維持の実装ポイント
- OCRで得た`bbox(x,y,w,h)`を保持
- フォントサイズは「ボックス内に収まるまで自動縮小」
- 改行位置は「句読点優先 + 禁則処理」
- 画像・図版レイヤーは原本をそのまま再利用
- 1ページごとに「原文/訳文オーバーレイ差分」を目視確認可能にする

---

## 5. 実装順（2週間MVP）
1. PDF→ページ画像化 + OCR抽出JSON
2. 用語集対応の翻訳API
3. bbox固定の再配置PDF生成
4. 数値・型番の検証ロジック追加
5. UIで差分プレビューと手動微修正

---

## 6. 最小データ構造（例）

```json
{
  "page": 1,
  "blocks": [
    {
      "id": "b1",
      "bbox": [120, 220, 460, 80],
      "lang": "fr",
      "source": "Chronomètre certifié",
      "target": "公認精度規格のクロノメーター",
      "style": {"font": "Times", "size": 13, "align": "left"}
    }
  ]
}
```
